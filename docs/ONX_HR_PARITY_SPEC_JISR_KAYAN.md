# ONX HR — مواصفة التكافؤ والتشريح مقابل جسر وكيان
**ONX_HR_PARITY_SPEC_JISR_KAYAN v1.0 — ٢١ أغسطس ٢٠٢٦**

> قرار المؤسس: نظام HR في منصة أونكس يجب أن يبلغ مستوى **جسر (Jisr)** و**كيان (KayanHR)**.
> الحقيقة الحالية المحققة بالفحص الحي: البنية موجودة (~18 وحدة، 70+ صفحة، كلها 200)
> لكنها **هياكل بلا عمق وظيفي** — موظف واحد، سجل حضور واحد، صفر مسيّرات.
> هذه الوثيقة هي المرجع الحاكم لبرنامج موجات HR حتى التكافؤ.

---

## ١. التشريح — ماذا يملك المنافسان فعلياً

### جسر (Jisr) — الميزات الجوهرية
| القدرة | التفصيل |
|--------|---------|
| محرك رواتب سعودي | مسيّر شهري: أساسي + بدلات − استقطاعات؛ درجات رواتب؛ معاينة قبل الاعتماد؛ موافقة مزدوجة (Maker-Checker)؛ سجل تدقيق |
| امتثال GOSI | احتساب اشتراكات التأمينات (موظف/صاحب عمل، سعودي/وافد) بجداول نسب قابلة للتهيئة |
| حماية الأجور WPS/مدد | توليد ملف SIF متوافق للرفع على مدد؛ مطابقة الرواتب مع التحويلات البنكية |
| ربط قوى | مزامنة بيانات الموظفين/العقود/الإجازات مع منصة قوى |
| نهاية الخدمة EOS | احتساب مكافأة نهاية الخدمة وفق نظام العمل السعودي (م ٨٤/٨٥): نصف شهر × ٥ سنوات أولى + شهر لكل سنة بعدها؛ تدرّج الاستقالة (⅓، ⅔، كامل)؛ تصفية فردية وجماعية |
| حضور وانصراف | بصمة/تطبيق/جيولوكيشن؛ عمل إضافي ١٥٠٪؛ جداول رمضان؛ خصومات تأخير؛ **ربط فوري بالرواتب** |
| خدمة ذاتية | تطبيق موظف: طلبات إجازة، قسائم رواتب، خطابات، بيانات شخصية |
| توظيف ذكي + أداء | ATS بمساعدة AI؛ تقييم 360°؛ استطلاعات رضا |
| مصاريف وسفر | طلبات نفقات وتعويضات مربوطة بالرواتب |
| تعدد كيانات | فروع وكيانات متعددة، هياكل تنظيمية مخصصة |

### كيان (KayanHR) — الميزات الجوهرية
| القدرة | التفصيل |
|--------|---------|
| هياكل رواتب متعددة | عدة هياكل رواتب مربوطة بقوانين محلية لكل دولة؛ قسائم إلكترونية |
| حضور متكامل | بصمة/GPS/جوال بلا أجهزة إضافية؛ مناوبات وجداول؛ تقارير حضور قابلة للتخصيص |
| محرك إجازات | كل الأنواع (سنوية/مرضية/استئذان)؛ أرصدة تلقائية؛ إشعارات مديرين؛ **احتساب في الرواتب** |
| خدمة ذاتية كاملة | بوابة موظف: طلبات، مستندات رسمية، كشوف رواتب، متابعة غياب |
| منشئ تقارير | تقارير رواتب/حضور/إجازات/أداء مخصصة + تصدير متعدد الصيغ + KPIs |
| إدارة تنظيمية | عقود، فروع، إدارات، مسميات، هياكل؛ API مرنة للتكامل |
| تعدد دولي | لغات وعملات متعددة، قوانين وضرائب لكل دولة |

## ٢. المصفوفة — فجوة أونكس مقابل التكافؤ

| # | القدرة (مستوى جسر/كيان) | حالة أونكس الآن | الفجوة | الموجة |
|---|--------------------------|------------------|--------|--------|
| P1 | دورة حياة موظف E2E (توظيف→onboarding→حضور→راتب→GL) | هياكل منفصلة غير مثبتة كسلسلة | إثبات + إصلاح السلسلة | **HR-1** (جارية) |
| P2 | محرك مسيّر رواتب: أساسي+بدلات−استقطاعات، درجات، معاينة، Maker-Checker، قسائم | payroll/payroll-runs هياكل CRUD فقط | محرك احتساب حقيقي + اعتماد مزدوج + قسيمة PDF/عرض | **HR-2** |
| P3 | GOSI: جدول نسب قابل للتهيئة (سعودي/وافد، موظف/صاحب عمل) محسوب في كل مسيّرة | غير موجود | جدول contribution config + احتساب في المحرك | **HR-2** |
| P4 | حضور عميق: مناوبات، عمل إضافي ١٥٠٪، جداول رمضان، خصم تأخير، **ربط بالمسيّرة** | attendance CRUD أساسي | محرك سياسات + تغذية المسيّرة | **HR-3** |
| P5 | محرك إجازات: أرصدة تراكمية، أنواع نظامية سعودية، موافقات، **أثر في المسيّرة** | leave CRUD أساسي | محرك أرصدة + تكامل رواتب | **HR-3** |
| P6 | نهاية الخدمة EOS: م ٨٤/٨٥ كاملة + تدرّج استقالة + تصفية | غير موجود (offboarding هيكل فقط) | حاسبة EOS + ربط offboarding→تصفية→GL | **HR-4** |
| P7 | WPS/مدد: توليد ملف SIF صالح | غير موجود | مولّد SIF (صيغة مدد) من المسيّرة المعتمدة | **HR-4** |
| P8 | خدمة ذاتية: قسائم رواتب، طلبات، خطابات (تعريف/راتب) | صفحات هياكل | ربط فعلي بالبيانات + توليد خطابات من hrLetters | **HR-5** |
| P9 | منشئ تقارير HR + KPIs | performance-metrics هياكل | تقارير فعلية من بيانات حية (رواتب/حضور/إجازات) | **HR-5** |
| P10 | توظيف→عرض→عقد + أداء 360 + استطلاعات | recruitment/onboarding هياكل | تعميق مؤجل بعد النواة المالية | **HR-6** |
| P11 | قوى/أبشر تكامل حكومي حي | غير موجود | **خارج النطاق حالياً** (يتطلب اعتماد حكومي/أسرار) — يُبنى كـexport/import format فقط | مؤجل |
| P12 | تعدد كيانات/فروع | موجود بالتصميم (branch-scoped بكل الراوترات) | ✅ ميزة قائمة | — |

**ملاحظة انضباط**: التكاملات الحكومية الحية (مدد/قوى/GOSI API) تتطلب تسجيلاً رسمياً وأسراراً حكومية — التكافؤ المطلوب في هذه المرحلة هو **تكافؤ المحرك والصيغ** (الاحتساب الصحيح + ملفات التصدير المتوافقة)، وهو ما يملكه جسر وكيان جوهرياً.

## ٣. برنامج الموجات (كل موجة = جلسة تنفيذ + PR + مراجعة منسق + دمج + نشر حاكم)

| الموجة | النطاق الحصري | معيار القبول |
|--------|---------------|--------------|
| **HR-1** | العمود الفقري: إثبات/إصلاح hire→onboarding→attendance→payroll→GL + سكربت OCMBR-007 | السلسلة تعمل E2E باختبار تكاملي؛ قيود GL متوازنة |
| **HR-2** | محرك المسيّرة: احتساب (أساسي+بدلات−استقطاعات)، جدول GOSI config، معاينة، Maker-Checker، قسيمة | مسيّرة تجريبية كاملة بأرقام صحيحة مثبتة باختبارات؛ GOSI سعودي/وافد صحيح |
| **HR-3** | الحضور والإجازات العميقة: سياسات overtime/تأخير/رمضان + أرصدة إجازات + تغذية المسيّرة | حضور وإجازات شهر كامل تنعكس صحيحاً في مسيّرة الشهر |
| **HR-4** | EOS + WPS: حاسبة نهاية الخدمة م ٨٤/٨٥ + مولّد SIF | حالات EOS الأربع (إنهاء/استقالة ٣ شرائح) صحيحة باختبارات؛ ملف SIF يطابق مواصفة مدد |
| **HR-5** | الخدمة الذاتية والتقارير: قسائم، خطابات، تقارير حية | موظف يرى قسيمته وخطاباته؛ ٥ تقارير جوهرية تعمل من بيانات حية |
| **HR-6** | التوظيف والأداء العميق: pipeline→عقد، تقييم 360 | دورة توظيف كاملة حتى إنشاء الموظف تلقائياً |

قواعد ثابتة لكل موجة: فرع جديد من main؛ migrations 0112+ idempotent + صيانة pins؛ كل بوابات CI؛ صفر لمس لـfinance routers/allowlist؛ PR فقط والدمج للمنسق؛ fail-honest.
